# homebrew-shogunai

Homebrew tap for [ShogunAi](https://github.com/LuxionServer/ShogunAi), a desktop orchestrator that automates the creation and management of isolated Git worktrees.

## Install

```bash
brew tap LuxionServer/shogunai
brew install --cask shogunai
```

## Update

```bash
brew upgrade --cask shogunai
```

The Cask in this tap is updated automatically by CI whenever a new [ShogunAi release](https://github.com/LuxionServer/ShogunAi/releases) is published.
